# Contributing to Neutron M693 Hardware Studio

Thank you for helping improve this experimental project.

- Open an issue describing the model, wired/2.4G/BT connection and Windows version.
- Include the version number and exact build log or %LOCALAPPDATA%\\NeutronM693HardwareStudio\\STARTUP_ERROR.log. Redact personal data and device serials.
- Test read-only operations first. Never submit an unverified firmware write path as stable.
- Keep source compatible with .NET Framework 4.x until the project intentionally migrates.
- Add or update a Windows CI smoke test for any startup/UI change.
- Don't include Redragon OemDrv.exe, bundled fonts, proprietary icons or unknown vendor assets.
- All contributions must be your own or properly licensed for distribution under MIT. Retain copyright and attribution notices.

By submitting a contribution, you agree that the included original code may be distributed under the repository's MIT License.
