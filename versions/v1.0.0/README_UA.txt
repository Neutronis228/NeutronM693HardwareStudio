Neutron M693 Smooth Clicker 1.0.0
=================================
Для Redragon TRIDENT M693-RGB (M693-RGB)

ЩО РОБИТЬ
----------
- Кнопка 4 / XButton1: за замовчуванням циклічний ЛІВИЙ клік.
- Кнопка 5 / XButton2: за замовчуванням циклічний ПРАВИЙ клік.
- Працює ТІЛЬКИ поки фізична бокова кнопка затиснута.
- Відпустили кнопку — цикл зупиняється відразу.
- Затримка між кліками не стрибає 10 -> 150 -> 70 мс, а плавно дрейфує.
- Діапазон, типовий інтервал і плавність задаються у вікні програми.
- За замовчуванням: min=10 мс, typical=45 мс, max=150 мс, smooth=88%.
- Налаштування зберігаються у %APPDATA%\NeutronM693SmoothClicker\settings.ini

ВАЖЛИВО: ЯК НАЛАШТУВАТИ REDRAGON SOFTWARE
------------------------------------------
Зараз на фото кнопки 4 і 5 у вас призначені на макроси самої миші.
Так наша Windows-програма не бачить фізичне DOWN/UP кнопки як XButton.

У Redragon M693 software зробіть:
1. Button 4 -> Back / Browser Back / XButton1.
2. Button 5 -> Forward / Browser Forward / XButton2.
3. Apply/Save. Якщо є запис у onboard profile/memory — збережіть профіль.
4. Після цього Redragon utility можна закрити. Драйвер видаляти не треба.

Neutron-програма перехоплює Back/Forward глобально і, коли ввімкнено
"Блокувати штатну дію", браузер назад/вперед не переходить.

ЗБІРКА
------
1. Розпакуйте ZIP у звичайну папку.
2. Запустіть BUILD_WINDOWS.bat.
3. Він використає штатний компілятор .NET Framework у Windows.
4. Після успішної збірки з'явиться:
   NeutronM693SmoothClicker.exe

ЗАПУСК
------
Запустіть NeutronM693SmoothClicker.exe або RUN.bat.
Адміністратор не потрібний для звичайних програм.
Якщо цільова програма запущена "Run as administrator", сам clicker теж
потрібно запустити від адміністратора через обмеження Windows UIPI.

ПРО ПЛАВНИЙ ІНТЕРВАЛ
---------------------
Алгоритм не вибирає кожну затримку незалежно. Нове значення сильно
залежить від попереднього: генерується цільова затримка, після чого поточна
затримка плавно рухається в її бік із додатковим обмеженням швидкості зміни.
Тому виходить крива/дрейф, а не різкі випадкові стрибки.

РЕКОМЕНДОВАНІ СТАРТОВІ ЗНАЧЕННЯ
--------------------------------
Min:      10 мс
Typical:  45 мс
Max:     150 мс
Smooth:   88%

Для ще швидшого режиму можна зменшити Typical до 30-35 мс.
Для спокійнішого — 55-70 мс.

БЕЗПЕКА / СУМІСНІСТЬ
---------------------
Це звичайна Windows-автоматизація через SendInput. Вона не перепрошиває
мишу і не торкається firmware, тому немає ризику "зацеглити" M693.

Вона НЕ є засобом обходу античіту/детекторів і не гарантує невиявність.
Деякі програми або ігри можуть розпізнавати чи забороняти інжектований input.
Використовуйте автоматизацію там, де це дозволено правилами програми/гри.

ЯКЩО КНОПКИ 4/5 НЕ РЕАГУЮТЬ
---------------------------
1. Перевірте, що у Redragon software вони НЕ Macro, а Back/Forward.
2. Натисніть Apply/Save.
3. Закрийте Redragon utility і перезапустіть Neutron clicker.
4. Поміняйте Button 4/5 місцями у вікні Neutron, якщо XButton1/XButton2
   у вашому профілі виявились переставлені.
5. Якщо цільова програма запущена від адміністратора — запустіть clicker
   теж від адміністратора.
