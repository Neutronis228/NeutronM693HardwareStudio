Neutron M693 Direct HID 1.1.0
=============================
Для Redragon TRIDENT M693-RGB.

ГОЛОВНА ВІДМІННІСТЬ ВІД 1.0.0
------------------------------
Ця версія НЕ вимагає перепризначати Button 4/5 на Back/Forward.
Вона НЕ використовує XButton1/XButton2 як тригер.
Вона слухає RAW HID-звіти пристрою і навчається безпосередньо на фізичному
стані бокової кнопки, якщо M693 віддає цей стан у своїй HID-колекції.

Тобто ваші поточні Redragon-профілі/макроси можна залишити як є.

ПЕРШИЙ ЗАПУСК
-------------
1. Розпакуйте архів.
2. Запустіть BUILD_WINDOWS.bat.
3. Запустіть NeutronM693DirectHID.exe.
4. Нічого в Redragon Software не міняйте.
5. Натисніть «Навчити фізичну 4».
6. Після цього натисніть ТІЛЬКИ кнопку 4, потримайте приблизно 1 секунду,
   потім відпустіть.
7. Дочекайтеся «Готово: фізична кнопка 4 прив'язана напряму через HID».
8. Так само навчіть кнопку 5.
9. Натисніть «Зберегти».

За замовчуванням:
Button 4 -> лівий клік
Button 5 -> правий клік
Min 10 ms / Typical 45 ms / Max 150 ms / Smooth 88%.

ЩО РОБИТЬ «ГЛУШИТИ СТАРИЙ МАКРОС»
----------------------------------
Якщо у Redragon Software Button 4/5 уже мають старий L/R click macro,
він інакше працюватиме ПАРАЛЕЛЬНО з новим плавним генератором.

Тому опція за замовчуванням увімкнена. Вона:
- НЕ перехоплює Back/Forward;
- НЕ перехоплює клавіатуру;
- НЕ змінює профіль мишки;
- тільки під час фізично затиснутої 4/5 глушить старі звичайні L/R події;
- власні кліки Neutron позначені спеціальним SendInput marker і проходять.

Нюанс Windows: поки 4/5 затиснута і глушиться відповідний L/R macro,
звичайне ручне натискання тієї ж L/R кнопки теж буде приглушене. Після
відпускання 4/5 все одразу повертається до звичайної роботи.

ЯКЩО DIRECT HID НЕ НАВЧАЄТЬСЯ
------------------------------
Це означає не помилку Back/Forward, а те, що конкретний режим M693
(USB / 2.4G / BT) не віддає фізичний side-button state у доступну Windows
RAW HID collection або віддає його іншим форматом.

Тоді:
1. Натисніть «Пересканувати HID».
2. Натисніть «Навчити фізичну 4», потримайте 4 приблизно секунду, відпустіть.
3. Повторіть для 5.
4. Натисніть «HID діагностика» і збережіть TXT.
5. Надішліть TXT — по реальних байтах M693 можна зробити точний профіль
   без зміни Redragon-настройок.

ПРОШИВКА / ONBOARD MEMORY
--------------------------
Ця версія НЕ перепрошиває M693 і НЕ записує невідомі feature-report команди
у firmware/onboard memory. Це навмисно: протокол M693 не документований, а
писати неперевірені байти в профіль миші без USB capture офіційної програми
було б ризиковано.

Direct HID тут використовується тільки для ЧИТАННЯ стану фізичних кнопок.

АНТИЧІТ / ВИЯВЛЕННЯ
-------------------
Програма не є засобом обходу античітів чи систем виявлення автоматизації.
Кліки генеруються стандартним Windows SendInput.
