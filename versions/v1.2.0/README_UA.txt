Neutron M693 Direct HID 1.2.0 FIX2
=================================
Для Redragon TRIDENT M693-RGB.

ЦЯ ВЕРСІЯ НЕ ВИМАГАЄ МІНЯТИ НАЛАШТУВАННЯ В REDRAGON SOFTWARE.
Вона також НЕ встановлює глобальний фільтр, що блокує ваші L/R-кліки.

Чому 1.1.0 у вас показувала 0:
--------------------------------
1.1.0 помилково шукала лише пристрої типу RIM_TYPEHID.
Звичайна миша в Windows Raw Input зазвичай приходить як RIM_TYPEMOUSE.
Тому напис «HID-колекцій: 0» не означав, що M693 відсутня — це була помилка програми.

Що зробити:
-----------
1. Розпакувати FIX2 у нову папку.
2. Запустити BUILD_WINDOWS.bat.
3. Запустити NeutronM693DirectHID.exe.
4. У верхньому блоці має бути щось на кшталт:
   RAW/HID: мишей=1 (або більше), додаткових HID-колекцій=...
5. Натиснути «Навчити фізичну 4».
6. Затиснути саме бокову кнопку 4 приблизно на секунду і відпустити.
7. Повторити для кнопки 5.

Програма приймає як справжній прямий сигнал тільки:
- XBUTTON1/XBUTTON2 конкретної RAW MOUSE;
- або окремий HID-біт додаткової HID collection.

Вона НАВМИСНО не вчиться на LEFT/RIGHT від вашого старого макросу.

Якщо навчання знову не відбудеться:
-----------------------------------
1. Натиснути «RAW/HID діагностика».
2. Зберегти TXT.
3. До збереження/під час навчання кілька разів:
   - натиснути і потримати фізичну 4;
   - відпустити;
   - натиснути і потримати фізичну 5;
   - відпустити.
4. Надіслати TXT.

Як читати flags:
----------------
0x0040 / 0x0080 = XBUTTON1 down/up
0x0100 / 0x0200 = XBUTTON2 down/up
0x0001 / 0x0002 = LEFT down/up
0x0004 / 0x0008 = RIGHT down/up

Якщо при кнопці 4/5 видно тільки LEFT/RIGHT через задані H_Clicking/H_building, це означає:
сама прошивка миші вже перетворила фізичну кнопку на макрос ДО Windows.
У такому режимі Raw Input не має окремого «фізична кнопка 4».
Наступна версія тоді повинна працювати через vendor HID/protocol M693, а не через Back/Forward і не через перехоплення ваших кліків.

Збірка:
-------
BUILD_WINDOWS.bat використовує штатний .NET Framework C# compiler Windows.
