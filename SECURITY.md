# Security policy

Neutron M693 Hardware Studio is an experimental community project.

Please report vulnerabilities privately to the repository owner via the GitHub security contact mechanism when available; otherwise open a minimal issue that does not include proof-of-concept exploit details or secrets.

- Never post device serial numbers, Windows usernames, private file paths, or identifiable log data.
- Never execute unknown firmware commands on someone else's hardware.
- Before writing onboard settings, back up the readable profile.
- Third-party Redragon executables and assets are not distributed as part of this MIT-licensed project.
